## 2. Compilation Instructions

### Option A: Overleaf (Zero-Configuration)
1. Zip the entire `paper/` folder:
   - Include `main.tex`, `references.bib`, `IEEEtran.cls`, and the `figures/` folder.
2. In [Overleaf](https://www.overleaf.com), select **New Project** $\to$ **Upload Project** and select the zip file.
3. Set the compiler to **pdfLaTeX** or **TeX Live 2024**.
4. Click **Recompile**. The document will compile cleanly to `main.pdf`.

### Option B: Local TeX Live / MacTeX / MiKTeX
Run the standard LaTeX compilation sequence:
```bash
pdflatex main
bibtex main
pdflatex main
pdflatex main
```
Or use `latexmk`:
```bash
latexmk -pdf main.tex
```
